# Everest Nepal Tours

## Overview
- Frontend: Next.js (`client/`)
- Backend: Express + Sequelize (`server/`)
- Database: Neon Postgres (managed)

## Local Development
Frontend:
```
cd client
npm install
npm run dev
```

Backend:
```
cd server
npm install
npm run dev
```

See `DEPLOYMENT.md` for Vercel + Render + Neon setup.
